🌙 小熊毛毛找月亮

📅 2026.05.21🏷️ 耐心 · 陪伴

森林里住着一只圆滚滚的小棕熊，名叫毛毛。他有一双黑亮的眼睛，还有一个粉粉的小鼻子，走路的时候总是摇摇摆摆的，特别可爱。

有一天晚上，毛毛趴在窗边，望着天空。

"咦？月亮呢？"他揉揉眼睛，天上一片黑，星星稀稀落落，月亮不见了！

毛毛很着急，因为他每天晚上都要看着月亮才能睡着。他赶紧套上小黄鞋，推开门，走进了夜晚的森林。

草叶上的露水打湿了他的小脚，风轻轻地吹，树叶沙沙作响。

"月亮，你在哪里？"毛毛小声问。

走着走着，他遇见了小松鼠果果，果果正抱着一颗大松果坐在树桩上。

"果果，你看见月亮了吗？"毛毛问。

果果歪着脑袋想了想，说："我没看见月亮，但是我看见了你呀！你要去哪里？"

"我要去找月亮。"毛毛说。

"我陪你去！"果果蹦下树桩，把松果夹在腋下，跟在毛毛身后。

两个好朋友一起走啊走，来到了小河边。小河里的水静静地流，月亮倒映在水里，圆圆的，亮亮的，就像一个白银盘子。

"月亮！月亮在这里！"毛毛高兴地跳起来。

他俯下身，想把月亮捧起来，但手刚碰到水，月亮就碎成一圈一圈的波纹，消失了。

毛毛愣住了，有些难过。

果果拍拍他的肩膀，说："毛毛，你抬头看——"

毛毛慢慢抬起头。原来，厚厚的云朵慢慢飘走了，月亮从云后面探出了圆圆的脸，把银白色的光洒在森林里，洒在小河上，也洒在毛毛和果果的身上。

"哇——"两个小伙伴同时轻声叫了出来。

月亮好像在对他们笑。

毛毛不再觉得害怕，心里暖暖的。他握住果果的小爪子，说："原来月亮一直都在，只是躲在云里睡觉呢。"

果果点点头，打了个小哈欠："说到睡觉……我也困了。"

"我也是。"毛毛也打了个大大的哈欠。

两个好朋友慢慢走回家，月亮静静地跟在他们身后，照着他们回家的路。

毛毛爬上软软的小床，裹好被子，透过窗户看着天上圆圆的月亮，微笑着闭上了眼睛。

"晚安，月亮。"

"晚安，毛毛。"

寓意：有时候我们找不到的东西，其实从来没有离开过。耐心等一等，它就会回来。有好朋友陪在身边，夜晚也不再黑暗。

🌙 小雨滴回家的路

📅 2026.05.27🏷️ 互助 · 回家

春天的早晨，天空灰灰的，云层厚厚的。

一颗小雨滴住在云朵里，他的名字叫滴滴。滴滴圆圆的，透明透明，像一颗小小的玻璃珠。

"妈妈，"滴滴问云妈妈，"我今天可以出去玩吗？"

云妈妈温柔地说："当然可以。今天你要去大地上旅行，然后顺着小路回家。"

"回家？我们的家不是在云朵里吗？"

"你去了就知道了。"云妈妈笑了笑。

滴滴和好多好多小伙伴一起，从云朵里跳了下来。

哗啦哗啦——

他们变成了雨，落向大地。

滴滴落在了大树上。大树爷爷晃了晃叶子："小雨滴，谢谢你，我好久没喝水了。"

滴滴顺着树干往下滑，觉得好开心。他帮助了大树爷爷！

从树上滑下来，滴滴落进了一条小沟里。小沟里有好多小伙伴，大家挤在一起往前流。

"我们要去哪里呀？"滴滴问。

"去小河！"前面的小伙伴喊。

可是，小沟中间被一块小石头挡住了。水流不过去，越积越多。

一只小蚂蚁站在石头旁边，急得团团转。

"怎么了？"滴滴问。

"我的家在石头那边，水堵住了，我过不去！"小蚂蚁快哭了。

滴滴想了想，对小伙伴们说："我们一起用力，把石头推开好不好？"

"好！"大家齐声说。

滴滴和小伙伴们一起冲向石头。推呀推，推呀推——

"咕噜！"石头终于被推开了！

水流一下子冲过去，小蚂蚁也顺着水流，安安全全地到了对面。

"谢谢你们！"小蚂蚁开心地挥着小触角。

滴滴继续往前流。小沟变成了小溪，小溪越来越宽，越来越宽。

他路过一片干干的菜地。白菜阿姨低着头，叶子都蔫了。

"好渴呀……"白菜阿姨有气无力地说。

滴滴和小伙伴们流过菜地，把水浇在白菜阿姨的根上。

"啊，好舒服！"白菜阿姨抬起头，叶子慢慢舒展开来，"谢谢你们，小雨滴！"

滴滴觉得自己越流越远了。可是他开始想家了。

"云妈妈说顺着小路就能回家，"滴滴对自己说，"可是回家的路在哪里呢？"

小溪流呀流，汇进了一条大河。大河好宽好宽，水流好急好急。滴滴有点害怕。

这时候，一条小鱼游过来："小雨滴，你是要去哪里呀？"

"我想回家，可是我不知道家在哪里。"滴滴说。

小鱼说："你跟着大河往前游，前面有一片大海。大海的水会被太阳晒得暖暖的，变成水汽飘到天上，那就回家啦！"

"真的吗？"滴滴的眼睛亮了。

"真的！我妈妈说的，所有的水滴最后都会回家的。"

滴滴鼓起勇气，跟着大河继续往前流。

终于，他看见了大海。大海好大好大，看不到边。蓝蓝的，亮亮的，太阳照在上面，闪闪发光。

滴滴流进大海，和大海里所有的水滴抱在一起。

太阳暖暖地晒着。滴滴觉得身体变轻了，慢慢地飘起来。

"我在飞！"滴滴惊喜地喊。

他越飘越高，越飘越高。他看见了下面的大海、大河、菜地和大树。

然后，他看见了一朵灰灰的云朵。

"妈妈！"滴滴激动地喊。

"欢迎回家，滴滴。"云妈妈张开怀抱。

滴滴扑进妈妈怀里，讲了这一路的经历——帮大树爷爷喝水，帮小蚂蚁过河，帮白菜阿姨解渴，还遇到了一条好心的小鱼。

"妈妈，"滴滴说，"回家的路好长好长，可是好开心。"

"因为呀，"云妈妈温柔地说，"你帮助了别人，别人也帮助了你。每一段路上，都有人给你指路。"

滴滴靠在妈妈身边，慢慢闭上了眼睛。

明天，他还会从云朵里跳下去，去大地旅行。

但不管走多远，他都知道——顺着小路，就能回家。

寓意：帮助别人的时候，你也在找到回家的路。每一段旅程中，善意都会变成照亮前方的光。

🌙 小蜗牛的星光花园

📅 2026.06.08🏷️ 互助 · 分享

从前，在一片绿油油的草地上，住着一只叫慢慢的小蜗牛。

慢慢的家是一座小小的蘑菇房子，门口有一块空地。慢慢很想有一个漂亮的花园，可是他没有花种子。

"没关系，"慢慢说，"我可以去找呀。"

✦ ✦ ✦

慢慢背着小房子出发了。他爬得很慢很慢，走一步，歇一歇。

路边的小蚂蚁看见了，问："慢慢，你要去哪里呀？"

"我想找花种子，种一个花园。"慢慢说。

小蚂蚁想了想，从家里搬出一颗小小的种子："这是我去年捡到的，送给你吧。"

"谢谢你！"慢慢高兴地收下了。

✦ ✦ ✦

慢慢继续往前爬。太阳公公把草地晒得暖洋洋的。

一只蝴蝶飞过来，落在慢慢身边："小蜗牛，你一个人要去哪里呀？"

慢慢把找种子的事告诉了蝴蝶。

蝴蝶拍拍翅膀说："我知道河边有好多漂亮的花，我带你去！"

蝴蝶飞在前头，慢慢跟在后面。走啊走，他们来到小河边。

河边的花可真多呀！有红的、黄的、紫的。花丛里散落着好多小小的花种子。

慢慢一颗一颗地捡，一颗一颗地放进小房子里。他捡了好多好多，小房子都快装不下了。

"谢谢蝴蝶！"慢慢开心极了。

✦ ✦ ✦

天色渐渐暗下来。慢慢该回家了。

可是路好远呀。慢慢爬呀爬，天黑黑的，他有点害怕。

这时，天上飞来一颗小星星。不，不是星星——是一只萤火虫。

萤火虫提着亮晶晶的小灯笼，飞到慢慢身边："别怕，我送你回家吧。"

萤火虫在前面照亮，慢慢跟在后面。草地上闪着一点一点的亮光，就像一条小小的星光小路。

✦ ✦ ✦

终于，慢慢回到了蘑菇房子。

第二天，慢慢把种子一颗一颗种在门口的空地上。

过了些日子，种子发芽了，长出了绿绿的叶子，开出了五颜六色的花朵。

小蚂蚁来看了，蝴蝶来看了，萤火虫晚上也来看了。他们都夸："慢慢的花园真漂亮！"

慢慢笑着说："这不是我一个人的花园。这是我们大家的花园。"

✦ ✦ ✦

从那天起，蘑菇房子前总是开着漂亮的花。白天有蝴蝶跳舞，晚上有萤火虫点灯。

慢慢常常趴在花瓣上看星星。他的花园不大，但是很温暖。

🌱 寓意：美好的事情，一个人很难做到，但大家一起帮忙，就能开出最美的花。接受了别人的帮助，也别忘了把快乐分享给大家。

🌙 小鸭子学游泳

📅 2026.06.24🏷️ 勇气 · 成长

从前，在一条弯弯的小河边，住着一群小鸭子。

鸭妈妈每天带他们去河里游泳。扑通扑通，小鸭子们一个个跳进水里，划着小脚丫，开心得嘎嘎叫。

可是，有一只叫毛毛的小鸭子，总是站在岸边不肯下水。

✦ ✦ ✦

"毛毛，快来呀！水里好舒服！"哥哥嘎嘎喊他。

"毛毛，快下来呀！我们一起玩！"姐姐花花也喊他。

毛毛摇摇头，把小翅膀紧紧地抱在一起："我怕……水太深了，我怕沉下去。"

鸭妈妈走过来，轻轻拍了拍毛毛的背："宝贝，你是鸭子呀，鸭子天生就会游泳的。"

"可是我从来没有游过……"毛毛小声说。

✦ ✦ ✦

鸭妈妈没有催他。她坐在毛毛身边，温柔地说："你知道吗？妈妈小时候第一次下水，也很害怕呢。"

"真的吗？"毛毛睁大了眼睛。

"真的。妈妈站在岸边看了好久好久，脚丫子都站累了。"鸭妈妈笑了笑，"后来，妈妈把一只脚放进水里试了一下——哇，水凉凉的，软软的，像在抱我的脚。然后妈妈又放进去另一只脚……就这样，一步一步，妈妈学会了游泳。"

毛毛想了想，低头看了看自己的小脚丫。

✦ ✦ ✦

"我可以先试一只脚吗？"毛毛问。

"当然可以。"鸭妈妈说。

毛毛小心翼翼地把一只小脚丫放进水里。河水凉凉的，软软的，轻轻地推着他的脚。

"感觉怎么样？"鸭妈妈问。

"好像……水在抱我的脚丫。"毛毛有点惊讶。

他深吸一口气，把另一只脚也放进了水里。河水托着他，像一张软软的床。

✦ ✦ ✦

"妈妈！水没有让我沉下去！"毛毛开心地喊。

"因为你是一只鸭子呀。"鸭妈妈笑着说，"你的脚丫会划水，你的羽毛不怕水，河水会一直托着你。"

毛毛试着划了一下小脚丫——他往前漂了一点点！

他又划了一下——又漂了一点点！

扑通扑通，毛毛在水里划起来了。虽然还游得不太快，可是他在游！他在真的游泳！

✦ ✦ ✦

哥哥嘎嘎和姐姐花花游过来："毛毛，你学会游泳了！"

毛毛开心地拍着小翅膀："我学会啦！原来水这么好玩！"

鸭妈妈在旁边看着，笑着摇摇头。她想起自己小时候第一次下水的样子——和毛毛一模一样呢。

✦ ✦ ✦

傍晚的时候，夕阳把小河照得金灿灿的。毛毛跟在哥哥姐姐后面，一划一划地游着。

河水软软地托着他，风轻轻地吹着他，鸭妈妈在岸边温柔地看着他。

毛毛想：原来，害怕的事情试一试，也许没有那么难。

而且，他发现了一件特别棒的事——他是一只鸭子，他真的会游泳。

🌟 寓意：害怕的时候，不用一下子全都做到。可以先试一小步，再试一小步。你会发现，你比自己以为的更勇敢，而且有些本领，一直就在你身上，等着你去发现呢。

🌙 小绵羊的白云被子

📅 2026.07.01🏷️ 感恩 · 安抚

夜晚，农场安静下来。月亮婆婆挂在天上，洒下银色的光。

小羊咩咩躺在自己的小床上，翻来覆去睡不着。

"好热呀，"咩咩嘟起嘴巴，"棉被太厚了，我的毛毛也太厚了。"

他爬起来，走到窗边。晚风吹过，带来一丝凉意。咩咩抬起头，看见夜空中飘着一朵小小的白云。

"白云白云，"咩咩小声说，"你可以做我的被子吗？我的棉被太热了。"

白云听见了，轻轻飘下来，像一团棉花糖一样柔软。

"我很轻，也很凉，"白云温柔地说，"但是我会飘走，你要抱住一颗星星，我才能停住。"

咩咩眨眨眼睛："星星那么高，我怎么抱住它呢？"

"闭上眼睛，"白云说，"对天上的星星说一声晚安，它就会把光亮放在你的睫毛上。"

咩咩乖乖闭上眼睛，轻声说："星星，晚安。"

一阵暖暖的亮光落在他的睫毛上。咩咩觉得眼皮变得轻轻的，好像真的有一颗小星星在陪着他。

白云慢慢盖在咩咩身上。它又软又凉，不像棉被那样重重的。咩咩觉得舒服极了。

"谢谢你，白云。"咩咩打了个小哈欠。

"现在，你也该对所有今天帮助过你的东西说晚安了。"白云轻轻摇晃着。

咩咩想了想，小声说："月亮婆婆，晚安。风姐姐，晚安。小草床，晚安。我的羊毛，晚安。"

每说一句晚安，他就觉得更安静一点。

远处，青蛙呱呱地唱着歌。咩咩没有害怕，因为那歌声就像摇篮曲一样好听。

"青蛙，晚安。"咩咩又说。

白云变得更薄更透明，像一层月光织成的纱。咩咩在白云被子下面，觉得自己像睡在一片安静的池塘里，又像睡在月亮的怀抱中。

慢慢地，咩咩的呼吸变得又长又慢。他的小鼻子动了动，嘴角翘起来，大概是在梦里吃到了甜甜的青草。

白云轻轻飞走了，留下一颗小星星在咩咩的头顶，一闪一闪，像一盏小小的夜灯。

月亮婆婆看着熟睡的小羊，笑着说："晚安，咩咩。"

寓意：学会在睡前向今天说晚安，让心里暖暖的、轻轻的，梦就会像白云一样温柔地来到你身边。晚安也是一种感谢，感谢所有陪伴过我们的事物。

🌙 小萤火虫的灯笼（池塘篇）

📅 2026.07.09🏷️ 自信 · 善意

夏天的夜晚，风轻轻地吹过田野，草丛里传来一阵阵"唧唧唧"的声音，那是小虫子们在唱歌。

后来，他在叶子底下遇到了一只小蚂蚁。小蚂蚁正推着一颗小面包屑，吃力地往前走。

"豆豆哥哥，"小蚂蚁抬起头，"你能帮帮我吗？我推不动了。"

豆豆想了想，他的好奇心让他想要继续往前飞。可是他看了看小蚂蚁红红的腿，再看了看圆滚滚的面包屑，忍不住停下来。

"好呀，我帮你。"豆豆说。

他和蚂蚁弟弟一起推呀推。推了好一会儿，"骨碌"一声，面包屑滚到了一个软软的土坑里，刚好掉进蚂蚁的家门口。

"哇，太棒了！"蚂蚁弟弟高兴得跳起来，"豆豆哥哥，你帮了我一个大忙！晚上你来我家吃饭好不好？"

豆豆有点不好意思地笑了："好呀。"

那天下午，豆豆在蚂蚁家吃了一顿小小的晚餐——几粒甜甜的糖屑和一滴凉凉的露水。

太阳要下山了，天边变成了橘红色。

豆豆飞回家，趴在卷心菜叶上，抬头看妈妈。

妈妈什么都没问，只是笑眯眯地看着他。

"妈妈，"豆豆小声说，"花蜜真的是甜的，露水真的是凉的，蚂蚁弟弟的家真的是软软的、暖暖的……"

"还有呢？"妈妈温柔地问。

"还有，"豆豆打了个小哈欠，"原来帮别人，比自己去看，还更开心一点点……"

妈妈轻轻笑了："是呀。好奇让你去看世界，可是有时候，停下来帮帮别人，世界会变得更甜哦。"

豆豆点点头，眼睛慢慢地眯起来。

花园里的夜很安静。萤火虫提着小灯笼从叶子间飞过，一闪一闪的。

豆豆把头埋进小被子里，心里想着：明天，他还要去看看别的花，尝尝别的味道。

当然，要是再遇到需要帮忙的小朋友，他还会停下来。

晚安，小瓢虫。晚安，花园。
